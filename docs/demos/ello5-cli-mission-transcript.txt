**System Map**

The ElloFive system consists of the following components:

1. Frontend:
	* Web interface on port 3000
	* Handles user input and sends requests to the API layer
2. API:
	* frc/server.js (/v1/chat, /v1/chat/completions, /run/:model)
	* Handles incoming requests from the frontend and returns responses
3. Agent Runtime:
	* Ollama models ellofive (qwen2.5:7b), ellofive-fast (llama3.2:3b)
	* Manages the execution of the agent code
4. Model Router:
	* Routes incoming requests to the correct model instance
5. Ello5/Ollama:
	* The core AI engine that powers the chatbot's responses
6. Tools/Memory/RAG/Sandbox:
	* bin/ellofive-memory (memory management)
	* bin/ellofive-agents (agent integration)
	* integrations/ello5-agent (agent functionality)
	* sandbox (untrusted code execution environment)
7. Infrastructure:
	* Ubuntu lab (environmental setup)
