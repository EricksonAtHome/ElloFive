# Elloten live demo transcript

Recorded against local Elloten at `http://127.0.0.1:3000` using model **Ello5 Fast**.

Proves the chat UI + Ello5 model work for real prompts:

| # | Prompt type | User ask |
| --- | --- | --- |
| 1 | Normal question | What is a dog? |
| 2 | Create code | Python `greet(name)` |
| 3 | Do a task | 4 steps for an HTML to-do app |
| 4 | Ask time | What time is it right now? |
| 5 | Ask news | Recent tech news (or known past story) |

## Observed replies (summary)

1. **Dogs** — domesticated mammal / Canis lupus familiaris; companion traits.  
2. **Code** — `greet(name)` with docstring + assert.  
3. **Task** — numbered HTML/JS to-do steps.  
4. **Time** — stated no live clock; approximate afternoon UTC.  
5. **News** — stated no live news; summarized a well-known past tech story (e.g. Steve Jobs, 2011).
